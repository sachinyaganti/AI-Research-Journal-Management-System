# AI-Enabled Research Journal Management and Peer Review System

## Overview

The AI-Enabled Research Journal Management and Peer Review System is a web-based application designed to manage the complete research paper lifecycle.

The system supports research paper submission, reviewer assignment, peer review, manuscript revisions, editorial decisions, and publication.

AI features will assist with reviewer recommendations and research paper analysis.

---

## User Roles

### Author
- Register and login
- Submit research papers
- Add co-authors
- Upload manuscripts
- Track paper status
- Upload revisions

### Reviewer
- View assigned manuscripts
- Accept or decline review requests
- Submit review reports
- Provide recommendations

### Editor
- Screen submitted papers
- Assign reviewers
- Monitor reviews
- Request revisions
- Accept or reject papers

### Admin
- Manage users
- Manage journals
- Manage categories
- Manage publication issues
- View analytics
